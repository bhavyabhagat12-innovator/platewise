## 3. APIs, Libraries & Third-Party Dependencies

PlateWise was deliberately built with a minimalist, high-efficiency dependency profile to maximize security, execution speed, and auditability:

### Runtime APIs & Services
* **Google AI Studio API (`gemini-1.5-flash`)**: Cloud LLM endpoint for structured culinary reasoning.
* **Vercel Serverless Platform**: Cloud runtime hosting serverless Node.js functions.

### Frontend Dependencies
* **Google Fonts (`Plus Jakarta Sans`, `JetBrains Mono`)**: Hosted typography loaded via standard HTTPS link tags with DNS preconnects.
* **Zero JavaScript Frameworks**: Zero runtime frameworks (No React, Vue, Angular, jQuery, or Lodash). All frontend interactivity is implemented in native Vanilla JavaScript (ES6+).
* **Zero Heavy Charting Libraries**: The spoilage risk bar chart and telemetry indicators are rendered natively using CSS hardware-accelerated animations and native DOM elements.

### Scientific Benchmarks & Emission Indices
* **United Nations Food and Agriculture Organization (FAO)**: Food waste greenhouse gas emission metrics (2019/2021 Food Wastage Footprint reports).
* **WRAP UK**: Perishability indicators and household food waste financial loss benchmarks.
