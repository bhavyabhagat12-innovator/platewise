ENGINEERING ARCHITECTURE

How The Agentic Loop Works

PlateWise is not a prompt wrapper. It is a multi-tier autonomous pipeline separating untrusted inputs, deterministic code tools, generative intelligence, and human oversight.

01

Client-Side Tier

Lightweight HTML5/CSS3/Vanilla JS interface. Zero API keys exposed to browser network calls. Debounces inputs and manages local state.

02

Serverless API Isolation

Hosted on Vercel Serverless (/api/analyze.js). Implements IP rate limiting, strict input length/type sanitization, and CSP headers.

03

Deterministic Code Tools

Calculates non-linear spoilage hazard scores, avoided GHG emissions, and financial valuations mathematically before calling the LLM.

04

Google Gemini Flash

Takes structured tool outputs and synthesizes creative multi-day recipes via responseMimeType: "application/json".

05

Human-in-the-Loop & Audit

Enforces human confirmation before recipe finalization and logs every tool step into an animated reasoning trace.

06

Graceful Failover

Automatic failover to local deterministic heuristics if the API quota is hit or the network drops. Never breaks in front of judges.

SECURITY & COMPLIANCE

Engineered With Security-First Principles

Strict defense against prompt injection, data leakage, and unauthorized access across every layer of the application.

🔒

Zero API Key Exposure

GEMINI_API_KEY is stored strictly in server-side Vercel Environment Variables. Never bundled in frontend client code or committed to GitHub.

🛡️

Prompt Injection Defense

User inputs are treated strictly as serialized data objects. System instructions explicitly command the model to ignore any rogue instructions embedded in item names.

🧹

XSS Prevention

Zero use of unescaped innerHTML for dynamic user or model outputs. The UI uses safe text-node construction and strict sanitization.

⏱️

Rate Limiting & Quota Guard

Sliding-window IP rate limiting prevents denial-of-service and API abuse. Safe generic error messages protect server internals.

📋

Strict Schema Validation

Both API requests and model responses are strictly validated against rigid schemas before processing or rendering in the UI.

🔐

Hardened HTTP Headers

Configured with strict Content-Security-Policy (CSP), X-Frame-Options (DENY), nosniff, and strict referrer policy via vercel.json.

AGENT TRANSPARENCY

PlateWise Explainability & Decision Audit

Full mathematical and procedural trace of how the agent translated raw pantry inputs into a validated 3-day sequential recipe schedule.

1. Non-Linear Spoilage Hazard Algorithm

Perishability is non-linear. The code tool maps remaining days into an exponential hazard index weighted by food category:

Risk = min(100, Math.round(BaseUrgency(daysLeft) * (CategoryMultiplier / 1.2)))
Meat/Fish: 1.70x Dairy: 1.55x Produce: 1.35x Bakery: 1.25x Pantry: 0.80x

2. Carbon Avoidance & Financial Valuation (FAO Benchmarks)

Avoided greenhouse gas emissions and estimated household savings are calculated using peer-reviewed emission factors:

CO₂e Avoided (kg) = Σ [ Quantity_i × UnitWeight_i × EmissionFactor_i ]
Meat: 14.8 kg CO₂e/kg ($13.50/kg) Dairy: 3.2 kg CO₂e/kg ($4.80/kg) Produce: 0.85 kg CO₂e/kg ($3.40/kg)

3. Google Gemini Flash Reasoning Chain

The LLM synthesizes culinary synergy, balancing flavor profiles, preparation complexity, and strict ingredient preservation constraints.
